# 角色形象设定（2D 试炼）

> 9 位英雄 + 13 种怪物，每位一套专属形象。全部由代码绘制（`角色形象.js`），无外部素材。
> 验收入口：直接打开 `其他/角色形象预览.html`（与游戏里跑的是同一份代码，看到什么战场就是什么）。

---

## 一、设计三原则

1. **剪影优先** —— 64px 高、还在快速移动的角色，唯一能瞬间读懂的是轮廓。所以每个角色的**体型（高低胖瘦）+ 头饰外轮廓 + 武器轮廓**都不同。
2. **配色即身份** —— 每个角色的主色与其技能特效色、HUD 语义色同源：紫=奥术 / 绿=游侠 / 青=守护与贤者 / 金=神圣与精英 / 玫红=深渊爪牙 / 血红=层主 / 骨白=亡灵。
3. **一套部件库拼出 22 个角色** —— `head / weapon / offhand / legs / extras` 五个部件族 + 体型参数，共享代码却互不相似；新增角色只需加一行参数。

绘制约定与 `试炼2D.js` 一致：单元 64×64，脚底 y≈60，脚下一道柔和投影。

> **机制型三只（bulwark / weaver / sacrificer）没有新增任何绘制代码**，全部由现有部件族重新组合而成。
> 但这里有一条**被实测逼出来的修正**，值得记下来：
> 最初三只都是「同族部件整套照搬、只换配色」，复测却发现 ——
> `bulwark/guard` 的剪影差异只有 **11.2%**（全池最接近的一对，比两位首领之间还像），
> `sacrificer/necro` 则**墨迹宽度逐像素相同**（同为 53px）。
> 也就是说：**只换配色并不满足本节那条第一原则（剪影优先）**。
> 后来改成每只换掉一个**支配轮廓的部件**：铁壁兵丢掉塔盾换圆盾、献祭者丢掉骨面改无面兜帽并去掉武器
> （织网者从一开始就用「四足 + 无武器」这个独有轮廓，没这个问题）。
> 复测后三只与同族的差异升到 **28.3% / 17.6% / 13.6%**，落回既有角色对的正常区间。
> **结论：复用部件可行，但"区分"必须落在支配轮廓的那个部件上 —— 配色只是第二层保险。**
> 另外，游戏中还有体型 `scale`、头顶名字标签两层区分，像素剪影只是最外面那一层。

**帧率随动作数量走**：招式多的怪物（骷髅骑兵、镜像怪、两位首领、两个冲锋单位）帧率更高，动起来更利落，也让「这只有几套招式」从动作上就读得出来。默认走 6 / 攻击 10 / 受击 10 / 死亡 6 fps，倍率写在形象表的 `animRate` 里。

## 三之二、远程攻击（弹药也是形象的一部分）

游侠、法师、贤者的武器本来就是弓与杖 —— 普攻改成**专属远程攻击**，不再挥砍。弹药与角色同一套做法：代码绘制、按「外观 + 颜色」缓存、预览页可逐帧核对。

| 使用者的武器 | 弹药 | 外观 | 取色 |
|---|---|---|---|
| 游侠 · 长弓 | 箭矢 `arrow` | 细长箭杆 + 尾羽 + 三角箭头，3 帧拖尾闪动 | 游侠亮绿 `#9fe0c0` |
| 法师 · 法杖 | 奥术弹 `orb` | 双层圆核 + 三颗绕行光点，4 帧脉动自转 | 法师亮紫 `#c79aff` |
| 贤者 · 卷轴法杖 | 灵能波 `wave` | 新月波前 + 拖尾，4 帧逐渐张开变淡 | 贤者青 `#5fd0e0` |
| 骷髅骑兵 · 长矛 | 长矛 `spear` | 矛杆 + 绑绳 + 叶形矛尖 + 尾羽，3 帧反光 | 骨白 `#d8d8e8` |

- **镜像怪不新增弹药**：玩家是远程英雄时，它直接发射**同一种**弹药，颜色换成镜像紫 `#d0b0ff`。
- **攻击帧改读法**：远程英雄共用同一套 15 帧表，但攻击帧（8/9/10）按 `ranged` 改成「张弓/举杖蓄力 → 释放 → 收招」—— 长弓帧会拉弦搭箭、放弦回弹，法杖帧会把宝珠举高再推出。
- 弹药一律**朝右**绘制，游戏里按飞行方向整体旋转，所以帧只负责脉动与拖尾。

## 三之三、举盾帧（防御）

按 `S` / `↓` 举盾时用第 15 帧（索引 14）：**重心压低、身体微后仰顶着盾**，所有英雄身前还多一道**弧光盾**（角色强调色，实机里会随朝向翻转、完美格挡时闪金）。

- 拿盾的英雄（战士 · 圆盾 / 守护者 · 塔盾）：**盾牌从身侧移到身前**，压住躯干 —— 实测剪影 x 范围从 `4~49` 变成 `10~59`，一眼就是"挡"
- 没拿盾的英雄（法师 / 贤者 / 游侠 / 刺客 / 狂战士 / 圣骑士 / 暗影）：靠那道弧光盾读姿态，武器不动，只把重心压低
- 越界检查：9 位英雄的举盾帧全部收在 64px 内（最右到 59px），无裁切

## 四、技术实现

- **帧结构**：英雄 15 帧（待机2 / 跑4 / 起跳 / 下落 / 挥砍3 / 受击 / 倒地 / 翻滚 / **举盾**），怪物 7 帧（走2 / 起手 / 扑击 / 受击 / 死亡2）。
- **按需生成**：进游戏只生成当前英雄的精灵表；怪物在进入房间生成时按类型生成，纹理按 key 缓存，不会逐帧重建。
- **动画 key 不变**：英雄沿用固定的 `hero_idle / hero_run / …`（切换英雄时重建），所以 `play()` 的调用点一处都不用改；怪物用 `mob_<类型>_walk` 等按类型命名（同房间可混多种怪）。
- **镜像怪照玩家**：`ensureMobTexture(scene, 'mimic', heroId)` 用玩家英雄的体型与装备 + 镜像紫配色，并加一层紫色描边 —— 玩家换英雄，镜像怪跟着变。
- **血条贴合体型**：`视觉宽度`由离屏 canvas 实测每个角色所有帧的墨迹范围得出（`inkOf()`），敌人血条按它定宽 —— 实测最瘦 34px（刺客）到最宽 63px（岩浆行者 / 暗影）。
- **弹药按需生成**：`ensureShotTexture(scene, kind, color)` 按「外观 + 颜色」缓存（`rt_shot_arrow_9fe0c0` 之类），换英雄只多一张，不会逐帧重建；判定框 `bw/bh` 贴在可见墨迹上，不让弹道打中看不见的地方。

## 六、已知取舍

- **首领靠宽度而非高度**：64px 单元里，头顶还有角冠/鹿角时无法再拔高。层主与影之皇以**最宽的肩甲、最大的武器、最重的配色**营造压迫感。
- **长柄武器改斜持**：竖直长杆（矛/戟/镰）必然顶穿单元上沿，改为斜持并缩短，造型仍是长柄武器。
- **1px 贴边不算越界**：脚底投影与部分武器边缘会贴到单元边界 1px 内，肉眼不可见，也不再精修。
- **远程英雄没有跳劈**：普攻已经是远程，滞空按 J 变成「空中射击」（自动朝最近敌人），不再有近战下落攻击 —— 这是「不再是近战攻击」的必然结果。
- **动作数决定帧率是主观划分**：标准写死为「拥有两套以上攻击/移动模式」，如果有怪物你觉得不该快、或该更快，改它那一行的 `animRate` 即可。
